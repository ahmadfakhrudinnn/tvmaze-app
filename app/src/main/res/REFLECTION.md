# Reflection

## 1. Hal yang Dipelajari

Selama proses pengembangan TVMaze App, saya mempelajari cara membangun aplikasi Android menggunakan Kotlin dan Jetpack Compose. Saya juga memahami penerapan arsitektur MVVM dan Repository Pattern dalam aplikasi sederhana.

Selain itu, saya mempelajari cara menggunakan Retrofit untuk mengambil data dari API serta menggunakan StateFlow untuk mengelola state pada UI.

## 2. Tantangan yang Dihadapi

Beberapa tantangan selama pengembangan adalah memahami struktur project Android, menghubungkan aplikasi dengan API, serta memastikan data dari API dapat ditampilkan dengan benar pada UI.

Tantangan lainnya adalah memahami pengelolaan state seperti loading, success, dan error serta membuat unit test untuk ViewModel.

## 3. Solusi yang Dilakukan

Untuk mengatasi tantangan tersebut, saya mempelajari dokumentasi dan menggunakan bantuan AI sebagai alat bantu dalam memahami konsep, mencari kesalahan pada kode, dan menentukan alternatif solusi.

Setiap perubahan kode kemudian dijalankan dan diuji kembali di Android Studio untuk memastikan aplikasi dapat berjalan dengan baik.

## 4. Penggunaan AI

AI digunakan sebagai pendamping selama proses pengembangan, terutama untuk:

* Memahami requirement tugas.
* Membantu menyusun struktur project.
* Membantu implementasi Retrofit dan API.
* Membantu implementasi Jetpack Compose.
* Membantu memahami MVVM dan StateFlow.
* Membantu membuat unit test.
* Membantu debugging ketika terjadi error.

Penggunaan AI tetap disertai dengan proses pengecekan dan pengujian secara langsung pada project.

## 5. Pengembangan Selanjutnya

Jika aplikasi dikembangkan lebih lanjut, beberapa fitur yang dapat ditambahkan adalah:

* Pagination.
* Search TV Show.
* Informasi season dan episode.
* Informasi cast.
* UI testing.
* Peningkatan desain UI dan navigasi.

## 6. Kesimpulan

Proses pengembangan aplikasi ini memberikan pengalaman dalam membangun aplikasi Android yang mengambil data dari API dan mengelola data tersebut menggunakan arsitektur yang terstruktur.

Aplikasi yang dibuat telah memenuhi fitur utama yang ditentukan, dan proses testing dilakukan untuk memastikan fungsi utama berjalan sesuai dengan yang diharapkan.
