# AI Log

## Penggunaan AI dalam Pengembangan

AI digunakan sebagai alat bantu selama proses pengembangan aplikasi TVMaze App.

### 1. Perencanaan dan Struktur Project

AI digunakan untuk membantu memahami requirement tugas dan menentukan struktur project menggunakan pendekatan MVVM dan Repository Pattern.

### 2. Implementasi API

AI membantu dalam memahami penggunaan Retrofit untuk mengambil data dari TVMaze API dan membuat struktur model data yang sesuai dengan response API.

### 3. Implementasi UI

AI digunakan sebagai bantuan dalam membuat tampilan menggunakan Jetpack Compose, termasuk:

* Halaman daftar TV Show
* Card TV Show
* Halaman detail
* Loading state
* Error state
* Tombol retry
* Fitur share

### 4. ViewModel dan State Management

AI membantu memahami penggunaan `ViewModel`, `StateFlow`, dan Kotlin Coroutines untuk mengelola state aplikasi.

State aplikasi yang digunakan:

* Loading
* Success
* Error

### 5. Unit Testing

AI membantu dalam menyusun unit test untuk menguji kondisi:

* Berhasil mengambil data TV Show
* Gagal mengambil data TV Show

### 6. Debugging

AI digunakan untuk membantu menganalisis error dan memberikan alternatif solusi selama proses pengembangan.

Setiap solusi yang diberikan AI diperiksa dan dijalankan kembali di Android Studio untuk memastikan aplikasi dapat berjalan dengan baik.

## Catatan

AI digunakan sebagai alat bantu dalam proses pengembangan, bukan sebagai pengganti proses pemahaman dan pengujian kode oleh developer.
